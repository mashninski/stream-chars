# stream-chars

Аватары зрителей для стримов на Twitch через OBS: по нижней полосе экрана ходят персонажи с никами зрителей.

## Запуск
Нужен Node.js 20 или новее (`node -v`).

```
npm install
npm start
```

`npm install` — один раз (и после изменения `package.json`). `npm start` запускает программу; остановить — `Ctrl+C` в том же окне.

## Адреса
- `http://localhost:4700/overlay` — оверлей для OBS: Browser Source, 1920×1080.
- `http://localhost:4700/test` — тестовая панель: добавить/убрать зрителя без Twitch.

Порт и остальные настройки — `config.json`.

## Настройки (`config.json`)
- `port` — порт программы.
- `maxOnScreen` — сколько персонажей одновременно на экране.
- `overlay.width`, `overlay.height` — размер оверлея.
- `overlay.strip` — полоса, по которой ходят: `left`/`right` — границы по горизонтали, `groundY` — линия земли (px сверху).
- `overlay.scale` — во сколько раз увеличен пиксель арта.
- `overlay.walkSpeed` — скорость ходьбы, px/с.
- `overlay.walkDistance` — случайная длина шага, [от, до] px.
- `overlay.idlePause` — случайная пауза стояния, [от, до] с.

## Свои персонажи
Каждый персонаж — папка в `characters/`. Имя папки — имя персонажа: его зритель пишет в `!перс <імя>`. Без пробелов; лучше без «і» и «ў» — их нет на русской раскладке. Большие и маленькие буквы не различаются.

В папке два файла:
- `sheet.png` — лист кадров. Одна анимация — одна строка, кадры идут слева направо без промежутков. Все кадры смотрят **вправо** (влево программа отражает сама). Низ кадра — земля, ноги ставьте на нижний ряд пикселей. Фон прозрачный.
- `character.json` — описание листа:

```json
{
  "frameWidth": 32,
  "frameHeight": 32,
  "animations": {
    "idle":      { "row": 0, "frames": 2, "fps": 2 },
    "walk":      { "row": 1, "frames": 4, "fps": 8 },
    "jump":      { "row": 2, "frames": 2, "fps": 8 },
    "fall":      { "row": 3, "frames": 2, "fps": 8 },
    "land":      { "row": 4, "frames": 2, "fps": 10 },
    "shake":     { "row": 5, "frames": 4, "fps": 16 },
    "parachute": { "row": 6, "frames": 2, "fps": 3 }
  }
}
```

`frameWidth`, `frameHeight` — размер кадра в пикселях. У анимации: `row` — номер строки (сверху, счёт с 0), `frames` — сколько кадров, `fps` — кадров в секунду. Все семь анимаций обязательны: стоит, идёт, прыжок, падение, приземление, встряхивается, парашют. Увеличение на экране — `overlay.scale` в `config.json`, пиксели остаются чёткими.

Заменить заглушку: положите свои `sheet.png` и `character.json` в её папку или заведите новую папку и удалите ненужную. Код править не надо — перезапустите программу. В терминале будет список загруженных персонажей; с ошибкой в файлах персонаж пропускается, и написано почему. Зрителям, чей персонаж исчез, программа выдаст нового.

Заглушки рисует `npm run stubs` (`scripts/make-stubs.js`): перезаписывает только папки шести заглушек.
