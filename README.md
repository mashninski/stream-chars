# stream-chars

Аватары зрителей для стримов на Twitch через OBS: по нижней полосе экрана ходят персонажи с никами зрителей.

## Запуск
Нужен Node.js 20 или новее (`node -v`).

```
npm install
npm start
```

`npm install` — один раз (и после изменения `package.json`). `npm start` запускает программу; остановить — `Ctrl+C` в том же окне.

В PowerShell (синее или чёрное окно «Windows PowerShell») пишите `npm.cmd start` и `npm.cmd install`: просто `npm` там блокируется ошибкой «выполнение сценариев отключено в этой системе». В «Командной строке» (cmd) работает и `npm start`.

## Адреса
- `http://localhost:4700/overlay` — оверлей для OBS: Browser Source, 1920×1080.
- `http://localhost:4700/test` — тестовая панель: добавить/убрать зрителя без Twitch, сообщение, смена признаков героя, рейд.

Порт и остальные настройки — `config.json`.

## Настройки (`config.json`)
- `port` — порт программы.
- `maxOnScreen` — сколько персонажей зрителей одновременно на экране. Остальные ждут в очереди и выходят по порядку, когда кто-то уходит. Рейдеры сюда не входят.
- `entrances` — способы появления и как часто каждый выпадает: `edge` — выходит из-за края, `poof` — облачко, `fall` — падает сверху. Число — вес: `{ "edge": 2, "poof": 1, "fall": 1 }` — из-за края вдвое чаще. `0` или убрать строку — способ не выпадает.
- `triggers` — какое действие у какого источника: `message` — сообщение в чате (сейчас — кнопка «Паведамленне» тестовой панели). Значение — имя реакции (`jump` — прыжок) или сцены. Облако с текстом сообщения показывается всегда, кроме команд (начинаются с `!`).
- `bubble` — облако с сообщением: `maxChars` — сколько символов показать (длиннее — обрезается по слову с «…»), `maxWidth` — ширина облака, px, `maxLines` — строк не больше, `fontSize` — размер шрифта, px; висит `minSeconds` + `secondsPerChar` × длина текста, но не дольше `maxSeconds`, с. Новое сообщение того же зрителя заменяет облако.
- `colors` — диапазон «дальнего цвета» курток в OKLCh: `lightness` — яркость [от, до] (0–1), `chroma` — насыщенность [от, до], `hueStep` — шаг оттенка, градусов, `steps` — сколько ступеней яркости и насыщенности перебирать.
- `tiers.wings` — ступени крыльев: `{ "months": месяцев подписки, "value": id ступени из heroes/wings/ }`.
- `weights` — поправки к весам редкости по категориям (`{ "class": { "warrior": 2 } }`); пишет окно «Рэдкасць», руками не обязательно.
- `raid.maxCount` — сколько парашютистов спускается при рейде, не больше.
- `raid.staySeconds` — сколько секунд рейдеры гуляют, потом уходят.
- `raid.parachuteWindowSeconds` — сколько секунд после рейда новые зрители появляются на парашюте.
- `overlay.width`, `overlay.height` — размер оверлея.
- `overlay.strip` — полоса, по которой ходят: `left`/`right` — границы по горизонтали, `groundY` — линия земли (px сверху).
- `overlay.scale` — во сколько раз увеличен пиксель арта.
- `overlay.walkSpeed` — скорость ходьбы, px/с.
- `overlay.walkDistance` — случайная длина шага, [от, до] px.
- `overlay.idlePause` — случайная пауза стояния, [от, до] с.
- `overlay.jumpHeight`, `overlay.jumpTime` — высота прыжка на сообщение (px) и его длительность (с).
- `overlay.fallGravity` — ускорение падения, px/с².
- `overlay.parachuteSpeed` — скорость спуска на парашюте, px/с.
- `overlay.parachuteSpread` — разброс стартовой высоты парашютистов, px: чем больше, тем дольше приземляется вся толпа рейда.
- `overlay.poofTime` — длительность облачка, с.

## Свая графіка
Всё, из чего собираются герои, — папка `heroes/`. Новый класс, убор, крылья, реквизит, существо — новая папка; код не трогается. После правки — перезапустить программу: в журнале список загруженного, битое пропускается с объяснением.

```
heroes/
  body.json                 общая сетка тела: размер кадра, анимации (строки листа), точки привязки
  traits.json               реестр признаков героя (класс, пол, цвет, убор, крылья, ник…)
  classes/<id>/             класс: info.json + листы по полам (m-body.png, m-jacket.png, m-decor.png, f-…)
  hats/<id>/                головной убор: info.json + sheet.png
  wings/<id>/               ступень крыльев: info.json + sheet.png
  props/<id>/               реквизит сцен (меч, бутылка, бочка…)
  creatures/<id>/           существа сцен (стражник, тень, овцы, питомцы)
```

`<id>` — имя папки: латиница, цифры, `-`, `_` (оно же — в адресах и настройках). Название для людей — `title` в `info.json`.

**Тело (`body.json`).** Все классы и оба пола нарисованы на одной сетке: кадр `frameWidth`×`frameHeight` (32×32), одна анимация — одна строка листа, кадры слева направо, все смотрят **вправо** (влево программа отражает сама), ноги — на нижней строке кадра, фон прозрачный. `animations` — `{ "имя": { "row", "frames", "fps", "loop", "anchors" } }`: `row` — строка (с 0), `frames` — сколько кадров, `fps` — кадров в секунду, `loop: false` — проиграть один раз и держать последний кадр. `anchors` — точки привязки по кадрам: `head` (макушка — сюда садится убор), `back` (спина — крылья), `handR`, `handL` (кисти — предмет в руке); точка `[x, y]` или `[x, y, поворот°]` (лёжа — убор повёрнут). `anchors` верхнего уровня — точки по умолчанию. `required` — обязательные анимации, `fallbacks` — что играть, если у класса анимации нет (дальше — `idle`).

**Класс (`classes/<id>/info.json`).**
```json
{
  "title": "Ваяр",
  "weight": 1,
  "layers": {
    "m": { "body": "m-body.png", "jacket": "m-jacket.png", "decor": "m-decor.png" },
    "f": { "body": "f-body.png", "jacket": "f-jacket.png", "decor": "f-decor.png" }
  },
  "animations": { "shout": { "row": 23, "frames": 2, "fps": 6 } }
}
```
Слои рисуются снизу вверх: крылья → `body` (тело, голова, причёска) → `jacket` → `decor` (украшения класса) → убор → предмет в руке. `jacket` — маска **в оттенках серого**: программа красит её в цвет героя, тени и блики сохраняются (серый 178 = ровно цвет героя, темнее — тень, светлее — блик). Все листы класса — на сетке тела: общие анимации в тех же строках, что в `body.json`, свои анимации класса (`animations`) — строками ниже. Лист короче — недостающие анимации заменяются запасными. `weight` — вес редкости по умолчанию (0 — не выпадает сам, дать можно из админки).

**Предмет со своим листом (убор, крылья, реквизит, существо).**
```json
{ "title": "Карона", "weight": 1, "image": "sheet.png", "frameWidth": 14, "frameHeight": 9, "anchor": [7, 7] }
```
`anchor` — точка предмета, которая совмещается с точкой тела (у убора — низ, который садится на макушку; у крыльев — место у спины; у реквизита — где его держит рука). Анимации — как у тела (`animations`), без них — один кадр. У существ `group` — группа для выбора по весам (`pet` — питомцы рэйнджэра).

**Признаки (`traits.json`).** Запись: `id`, `title`, `type` (`item` — предмет категории `category`, `choice` — из `values`, `color`, `bool`), `appears` (когда появляется: `firstSeen`, `follow`, `subscription`, `firstMessage`, `twitch`), `pick` (как выбирается: `weights`, `farColor`, `tiers`), `admin` (меняется из админки), `points` (меняется за баллы), `optional`, `layer` (`{ "z", "anchor" }` — рисуется предметом по точке привязки). Новый признак (например, плащ) — запись здесь и папка `heroes/cloaks/`; админка и оверлей подхватят сами.

**Заглушки** рисует `npm run stubs` (`scripts/make-stubs.js`): перезаписывает только свои файлы в `heroes/`. Старые заглушки в `characters/` программа больше не читает — папку можно удалить.

**Импорт картинки** (лист поз на однотонном фоне) — `scripts/import-art.js`:
```
node scripts/import-art.js --in лист.png --cols 4 --rows 2 --names think,joy,panic,angry,drunk,sleep,rub_eyes,knocked --out heroes/classes/warrior --prefix m-import
```
Нарезает сетку, фон (`--key`, по умолчанию `#00ff00`) делает прозрачным, обрезает по персонажу, уменьшает все клетки одним масштабом до кадра тела, ставит ноги на нижнюю строку, сводит цвета к палитре (`--palette 16`), серые пиксели куртки (`--jacket #808080`) уносит в маску. Пишет `<prefix>-body.png`, `<prefix>-jacket.png` (строка на позу) и `<prefix>-import.json`. Проверка скрипта без картинки: `node scripts/import-art.js --selftest`. Все параметры — в начале файла.

## Новое поведение
Поведение собрано в таблицы — новое добавляется записью, остальной код не трогается:
- `public/js/actor.js` → `STATES` — состояние (что делает и какую анимацию играет), `ENTRANCES` — способ появления, `REACTIONS` — реакция поверх того, что персонаж делает (как прыжок на сообщение).
- Новый способ появления — запись в `ENTRANCES` и строка в `entrances` в `config.json`.
- Новая анимация — строка в листах класса и запись в `body.json` (общая) или `info.json` класса (своя). У состояния можно указать запасную анимацию (`fallback`), общие запасные — `fallbacks` в `body.json`.
- Эффект без графики (как облачко) — запись в `EFFECTS` в `public/js/render.js`.

## Для разработки
Программу можно запустить с другой папкой данных и другим портом — настоящие `data/` и порт не трогаются:

```
node src/server.js --data-dir D:\temp\sc-data --port 4710
```

То же переменными окружения: `STREAM_CHARS_DATA_DIR`, `STREAM_CHARS_PORT` (аргумент важнее).

- `--parent-pid <число>` — программа сама выходит, когда процесса с этим номером больше нет (проверка раз в 5 с). Так скрипт OBS останавливает её вместе с OBS.
- Файл `stop` в папке данных — сигнал «выйти» (проверка раз в секунду; файл удаляется).
- Второй запуск на занятом порту — строка в журнал и тихий выход (код 0).
- Журнал: терминал, файл `<папка данных>/logs/<дата>.log` (хранятся 7 последних), последние 500 строк — в админке.
- Настройки: `config.json` — значения по умолчанию (в git, программа его не меняет); `<папка данных>/settings.json` — только изменённое из админки, поверх. Неверное значение админка не сохраняет и пишет, что не так; неверная строка в `settings.json` при запуске пропускается со строкой в журнале. Всё, кроме порта, применяется без перезапуска.
