# Карта проекта stream-chars

Аватары зрителей для стримов на Twitch через OBS.

## Где что живёт
- **Источник правды — эта папка** (`D:\production\stream-chars`, git-репозиторий, связан с GitHub). Все документы здесь.
- **Проект claude.ai держит только правила работы** (поле Instructions). Содержания там нет. Причина: два комплекта одноимённых документов расходятся, и непонятно, какой настоящий.
- `CLAUDE.md` в корне — инструкция для Claude Code.
- `claude/project-instructions.md` — текст для поля Instructions проекта claude.ai. Только сам текст, переносится копированием файла целиком.
- Правило, нужное и в чатах приложения, и в Claude Code, стоит в двух местах: полностью в `CLAUDE.md`, коротко — в `project-instructions.md`. Это два входа для двух читателей, не дубль.
- Секреты — только в `.env.local` (в `.gitignore`).

## Порядок работ
1. ~~Описать первое направление~~ — сделано: `claude/avatars-spec.md`, `claude/avatars-plan.md`.
2. Аватары v1: задачи 1–6 из `claude/avatars-plan.md`, по очереди, каждая в своём чате Claude Code. Задача 4 делает и код героев (`claude/heroes-spec.md`) на заглушках.

## Деньги
Каждая новая функциональность приносит оценку $/мес и часы в свой `-plan.md`; сюда — итог.

| Статья | $/мес | Где оценка |
|---|---|---|
| Аватары зрителей v1 | 0 | `claude/avatars-plan.md` |
| Графика героев | 0 (разово 0–45 $, если генерация через API) | `claude/heroes-plan.md` |

## Правила ведения документации

**Журнал (`journal.md`)**
- Новая запись сверху, заголовок `## ДД.ММ.ГГГГ`, внутри `###` на каждое решение.
- Причина обязательна, и что отвергнуто — тоже.
- Задним числом не переписывается: решение отменено — новая запись с датой и причиной отмены, старая остаётся.
- Конкретные значения не копируются — ссылка на файл, где они лежат.
- За ~1500 строк записи старше трёх месяцев уезжают в `journal-archive.md`.

**Открытые вопросы (`open-questions.md`)**
- У каждой записи — кто решает.
- Вопрос закрылся → причина в журнал, запись отсюда удаляется.
- Закрытое решение в списке открытых — ошибка.
- Осознанная заглушка — в таблицу заглушек с этапом, который её закроет.

**Идеи (`ideas.md`)**
- Одна идея — один абзац: что, зачем, чем кончится, если не делать.
- Созрела → spec и plan, строка удаляется, в журнал «завели, потому что».
- Отброшена → строка удаляется, в журнал причина отказа.

**Задачи и цепочка чатов**
- Промпт задачи сначала пишется в `-plan.md`, потом отдаётся — одним готовым блоком. Есть дополнение, а исполнитель не запущен — вписать в промпт в плане и отдать собранный.
- Чат, закрывающий задачу, оставляет в `-plan.md` готовый промпт следующей и отмечает, что сделано.
- Параллельная работа — таблица раздачи в плане: промпт, чат, зависимость. Разные файлы — параллельно; общие — по очереди.

**Общее**
- Одно решение — в одном месте.
- Новая функциональность — сразу оценка $/мес и часы.
- Черновики остаются в чате.
