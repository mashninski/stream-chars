## Система генерации
1. **Стиль один раз.** Пиксель-арт, вид сбоку, персонаж смотрит вправо, силуэт читается в 32×32, 3–4 цвета на деталь, чёрный контур или без — решаем на Г1. Итог Г1 — «паспорт стиля»: абзац текста, который вставляется в начало каждого промпта, и 1–2 картинки-эталона, прикладываемые к каждой генерации.
2. **Развёртка персонажа** (класс × пол): спереди, сбоку, сзади, в полный рост, однотонный фон (чистый #00FF00 или другой, которого нет в персонаже — станет прозрачным). Куртка — нейтрально-серая: её цвет задаёт программа.
3. **Лист эмоций по шаблону**: развёртка прикладывается как эталон, промпт просит **сетку 4×2 одинаковых клеток**, в каждой — тот же персонаж в одной позе, вид сбоку вправо, ноги на одной линии, одинаковый масштаб. Порядок клеток фиксирован (чтобы нарезка была автоматической):
   `думает | радость | испуг | злость`
   `пьяный | спит (лёжа) | трёт глаза | отброшен (в полёте)`
   Второй лист тем же шаблоном — позы для ходьбы/бега/прыжка и анимаций класса (4×2, порядок — в промпте сессии).
4. **Импорт** (скрипт в `scripts/`, делает задача 4): картинка → нарезка сетки → фон по цвету-ключу в прозрачность → обрезка по персонажу и выравнивание ног по нижней линии → уменьшение до 32×32 ближайшим соседом → сведение к палитре → маска куртки (серые пиксели куртки → отдельный слой) → в папку класса.
5. **Анимация** — Claude Code по позам: кадры между позами, точки привязки (голова, спина, руки), строки листа, `character.json`. Правило: общие анимации тела — одни на всех, поэтому с развёрток берутся голова, причёска, украшения класса; тело — общее.
6. **Проверка** — на экране в OBS рядом с другими героями; правки — перегенерацией клетки, не всего листа.

## Шаблон промпта листа эмоций (под импорт `scripts/import-art.js`, уточняется на Г1)
Что ждёт импорт (иначе нарезка ошибётся):
- сетка **ровно 4×2 одинаковых клетки**, картинка PNG (JPEG — пересохранить в PNG);
- фон — **сплошной #00FF00**, без градиента, теней на земле, рамок, линий сетки, подписей: всё, что не фон, считается персонажем;
- персонаж в каждой клетке **целиком и с отступом** от краёв клетки (≥5 %), один масштаб во всех клетках — импорт уменьшает все клетки одним масштабом по самой крупной позе;
- ноги стоящих поз — на одной линии; лежачие позы — тоже на «земле» клетки;
- куртка — **нейтрально-серая** (основа около #808080, тени и блики — только серым); **больше ничего серого** у персонажа (доспех, волосы, металл — не серые), зелёного — тоже нет: серое уходит в маску куртки, зелёное — в прозрачность. Иначе — параметры `--jacket`, `--jacket-tolerance`, `--key-tolerance`;
- порядок клеток фиксирован: `think, joy, panic, angry` / `drunk, sleep, rub_eyes, knocked`.

```
[паспорт стиля]
Reference: the attached character turnaround. Same character, same outfit, same proportions, same colors.
Draw a sprite sheet: exactly 4 columns × 2 rows of equal square cells on a flat solid pure #00FF00 background.
No grid lines, no borders, no text, no ground shadows, no background objects.
Every cell: the full character with empty margin around it, side view facing right, feet on the same baseline, the same scale in every cell.
Row 1: thinking (hand on chin, looking up) | joy (arms up, happy) | fear (recoiling, scared face) | anger (fists, frowning).
Row 2: drunk (swaying, flushed) | sleeping (lying on the ground) | rubbing eyes | knocked back (flying backwards).
The jacket is flat neutral grey (#808080) shaded only with greys. Nothing else on the character is grey or green.
```

Импорт готового листа (пример — мужская версия ваяра, в пробную папку):
```
node scripts/import-art.js --in лист.png --cols 4 --rows 2 --names think,joy,panic,angry,drunk,sleep,rub_eyes,knocked --out heroes/classes/g1-proba --prefix m
```

## Промпт сессии Г1 (для чата с автором)
Не автономная: автор генерирует картинки, исполнитель пишет промпты, импортирует и показывает на экране. После задачи 5 (программа уже работает в OBS).

Прочитай: CLAUDE.md, claude/README.md, верхние записи claude/journal.md, claude/heroes-spec.md («Графика героя»), claude/heroes-plan.md (весь), README.md («Свая графіка»), scripts/import-art.js (параметры в начале файла), heroes/body.json и heroes/classes/warrior/info.json (формат).

Автор готовит заранее: 3–5 картинок пиксель-арта, которые нравятся (скриншоты игр, спрайты), доступ к Nano Banana 2 (приложение Gemini или API — вопрос claude/open-questions.md, решить в начале), 1,5–2 часа.

1. Стиль: вместе с автором по референсам — пиксель-арт вид сбоку, контур (чёрный / цветной / без), 3–4 цвета на деталь, пропорции (голова к телу), читаемость в 32×32 на тёмном и светлом фоне стрима. Записать 2–3 варианта словами.

Итог — «паспорт стиля»: абзац на английском для начала каждого промпта + картинка-эталон (сохранить в heroes/style/, в git).
3. Лист эмоций ваяра по шаблону claude/heroes-plan.md («Шаблон промпта листа эмоций»), с паспортом стиля и развёрткой как эталоном. Проверить глазами до импорта: 4×2, фон ровный, никто не касается краёв, серого и зелёного у персонажа нет.

Перезапуск программы, в «Праверка» — зритель, «Клас» → g1-proba; смотреть в OBS рядом с заглушками: читается ли силуэт, как красится куртка в разные цвета (сменить колер), видны ли эмоции.

7. Записать: паспорт стиля и решения — в журнал (стиль, контур, палитра, что отвергнуто), вопрос «стиль графики» — закрыть в open-questions; факт часов Г1 — в таблицу heroes-plan.md; промпт Г2 (развёртки 6 классов × 2 пола) — в heroes-plan.md.
