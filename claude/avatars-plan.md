ЭТАП A. Облако с сообщением и общий путь действий (спека «Действия и источники»)
A1. Одно событие действия программа → оверлей: `{ type: 'act', id, action, text? }`; `action` — имя из REACTIONS (public/js/actor.js). В src/viewers.js — метод вида `act(id, action, text)`, его вызывают все источники (тестовая панель, админ-панель, Twitch). Какое действие у какого источника — в config.json (`triggers`, например `"message": "jump"`), не в коде. Незнакомое оверлею действие — пропустить, строка в консоли браузера. Событие `message` заменить на `act` или оставить обёрткой — реши сам.
A2. Облако: сообщение → над персонажем облако с текстом, вместе с прыжком. Шрифт некрупный (~16 px, config.json); текст целиком до `bubble.maxChars` (100), длиннее — обрезать по слову и «…»; перенос по словам, ширина до `bubble.maxWidth` (280 px), не больше `bubble.maxLines` (4) строк; висит `bubble.minSeconds + bubble.secondsPerChar × длина` (2 + 0,05, не больше `bubble.maxSeconds` = 8). Облака — отдельным проходом поверх всех персонажей, программно, текст только через canvas (fillText). Логика (обрезка, перенос через переданную функцию измерения, время) — actor.js (`actor.say(text)`), рисование — render.js.
A3. Тестовая панель: поле текста сообщения рядом с «Паведамленне» (пусто — «тэставае паведамленне»). Настройки — config.json + README.md («Настройки»).
